# موقع فريق لمسة وفاء

موقع ثابت (HTML وCSS وJavaScript) جاهز للرفع على GitHub Pages، وما يحتاج أي تثبيت.

## الملفات

| الملف | وش فيه |
|---|---|
| `index.html` | الموقع الرئيسي |
| `links.html` | صفحة الروابط (Link in bio) تحطها في بايو حساباتكم |
| `team.js` | **أسماء الفريق وصورهم**، وهذا الملف اللي تعدّل فيه |
| `images/team/` | صور أعضاء الفريق |
| `assets/` | الشعار والتنسيق والأكواد (لا تحتاج تعدّل فيها) |

## إضافة اسم عضو أو صورته

1. افتح `team.js`.
2. لقِ المنصب، واكتب الاسم بين علامتي التنصيص:
   ```js
   name: "محمد العتيبي",
   ```
3. للصورة: ارفع الصورة داخل `images/team/` واكتب مسارها:
   ```js
   photo: "images/team/mohammed.webp",
   ```
   إذا الاسم فاضي يظهر «يُعلن قريبًا»، وإذا الصورة فاضية يظهر الشعار مكانها.

## الرفع على GitHub Pages

1. أنشئ مستودع جديد (Repository) على GitHub.
2. ارفع **محتوى** هذا المجلد كما هو (index.html يكون في أعلى المستودع، مو داخل مجلد ثاني).
3. من Settings ثم Pages: اختر Branch: `main` والمجلد `/ (root)` واضغط Save.
4. بعد دقيقة أو دقيقتين يصير الموقع على:
   `https://اسم-حسابك.github.io/اسم-المستودع/`
5. رابط البايو يكون:
   `https://اسم-حسابك.github.io/اسم-المستودع/links.html`
